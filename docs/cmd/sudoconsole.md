## sudoconsole

Secure sudo wrapper for CLI agents

### Synopsis

sudoconsole lets any CLI coding agent run sudo commands
without exposing the password, and enforces a security policy that
blocks remote-access and credential-exposure commands by default.

### Options

```
      --cache-timeout int   sudo cache timeout in seconds (60-3600); overrides config file
      --config string       path to the TOML config file (default: platform XDG/Application Support location)
      --format string       output format: human or json (overrides config file)
  -h, --help                help for sudoconsole
      --log-level string    log level: silent, error, warn, info, debug (overrides config file)
```
